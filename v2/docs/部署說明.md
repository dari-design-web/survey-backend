# 部署說明（Google Apps Script，約 5 分鐘）

使用帳號：**dari25420001@gmail.com**

## 1. 建立試算表與 Apps Script

1. 開啟 https://sheets.new，把試算表命名為「問卷系統資料（測試）」。正式環境之後另建一份「問卷系統資料（正式）」。
2. 選單「擴充功能 → Apps Script」。
3. 左側 `程式碼.gs`：全選並刪除原本內容，貼上 GitHub 上 `v2/gas/Code.gs` 的全部內容。
   - 原始檔網址：https://raw.githubusercontent.com/dari-design-web/survey-backend/main/v2/gas/Code.gs
4. 左側齒輪「專案設定」，勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。回到編輯器，把 `appsscript.json` 換成 GitHub 上 `v2/gas/appsscript.json` 的內容。
5. 按儲存（Ctrl+S）。

## 2. 執行 setup

1. 上方函式選單選 `setup`，按「執行」。
2. 第一次執行會要求授權：選擇帳號 →「進階」→「前往（不安全）」→「允許」。
   - 這是自己寫的程式，Google 會顯示未驗證警告，屬正常現象。
3. 下方「執行紀錄」會顯示超級管理者的帳號與密碼，請記下。
4. （選用）函式選單改選 `seedDemo` 再執行一次，建立範例問卷與 20 份測試贈品。

## 3. 部署為網頁應用程式

1. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」。
2. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按「部署」，複製網址（結尾為 `/exec`）。

## 4. 開啟自動更新

1. 開啟 https://script.google.com/home/usersettings。
2. 把「Google Apps Script API」切換為「開啟」。

開啟後，Claude 推送到 GitHub 的已測試版本會在 1 小時內自動套用，網址不變。

## 5. 填入網址

把第 3 步的 `/exec` 網址交給 Claude。Claude 會填入 `v2/web/config.js` 並推送到 GitHub，之後即可使用：

- 客人入口：https://dari-design-web.github.io/survey-backend/v2/web/
- 後台：https://dari-design-web.github.io/survey-backend/v2/web/admin/login.html

## 常見問題

| 狀況 | 處理 |
|---|---|
| 頁面顯示「尚未設定後端網址」 | `config.js` 還沒填入 `/exec` 網址 |
| 修改 Code.gs 後網站沒變 | 手動貼上的修改需要「部署 → 管理部署作業 → 編輯 → 版本：新版本」；或改用 GitHub 更新流程 |
| 自動更新失敗 | 後台「帳號」頁會顯示錯誤；通常是第 4 步的 Apps Script API 沒有開啟 |
| 忘記密碼 | 在 Apps Script 編輯器開啟 `admin_users` 分頁，請 Claude 協助重設 |
